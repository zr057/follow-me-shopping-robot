## 系统方案

<p align="center">
  <img src="assets/architecture/technical-route.png" width="920" alt="项目技术路线">
</p>

系统由四个部分组成：

1. **环境感知：** 激光雷达、视觉传感器和里程计获取环境与机器人状态。
2. **建图定位：** SLAM建立栅格地图并估计购物车位姿。
3. **路径规划：** 全局规划生成整体路线，局部规划处理附近障碍物。
4. **运动控制：** 将规划结果转换为速度指令，驱动差速底盘跟踪路径。

正式结题报告显示，项目最终主要完成了激光雷达链路，视觉目标识别和多模态融合尚未完成稳定集成。

## 核心算法工作

### 全局路径规划

使用二维栅格地图描述环境，基于A*搜索起点到目标点之间的无碰撞路径。主要工作包括：

- 八方向邻域扩展；
- 地图边界与障碍物检查；
- 基于启发函数的节点选择；
- 基于父节点的路径回溯；
- 冗余转折点删除与安全路径简化。

### 局部动态避障

局部规划器预测短时运动轨迹，排除可能发生碰撞的候选轨迹，并综合目标方向、障碍物距离、前进速度和全局路径偏差选择控制量。

### 轨迹跟踪控制

根据位置误差与航向误差生成线速度和角速度指令，通过闭环调节左右轮速度，使实体底盘跟踪规划路线。
